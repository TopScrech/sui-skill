# SUI skills

A collection of skills for Swift app development

## Available skills

| Skill | Purpose |
| --- | --- |
| [sui](skills/sui/SKILL.md) | SwiftUI, SwiftData, and Swift concurrency conventions for iOS apps |

## Structure

Each skill lives in `skills/<skill-name>/` with its own `SKILL.md` and optional supporting files such as `agents/openai.yaml`

To add another skill, create a sibling folder under `skills/` and add it to the table above

To install SUI manually, copy `skills/sui/` into your agent's skills directory
